# 纸间阅读器

纸间阅读器是完全离线的长文本 TXT 阅读器，采用 Kotlin + Jetpack Compose，支持编码自动识别、章节解析、四种翻页动画、书签与全文搜索，不申请任何权限（包括网络）。

仓库是一个单应用 Android 项目，阅读对象是本地 TXT 文件。打开文件时先识别文本编码，再根据章节标记切分内容，阅读页提供四种翻页动画，书签和全文搜索都直接在本地文本上完成。应用没有网络权限，也没有账号、同步或在线内容入口，导入文件依赖系统文件选择器授予的访问范围。

## 主要功能

- 自动识别常见 TXT 编码，减少打开文件时的乱码。
- 按章节标题解析长文本，适合长篇内容跳转。
- 四种翻页动画，可按阅读习惯切换。
- 书签定位与全文搜索，查找结果回到原文位置。
- 完全离线运行，不申请任何权限，包括网络权限。

## 技术结构

界面层使用 Kotlin 与 Jetpack Compose，项目采用单模块 Android 应用结构。阅读、章节、书签和搜索逻辑都在本机执行，不依赖服务端。仓库目前只包含应用源码和构建配置，没有附带在线书城、云同步或账号系统。

## 运行

用 Android Studio 打开仓库，等待 Gradle 同步完成，然后运行 `app`。应用不需要配置服务器地址或 API key，导入本地 TXT 后即可阅读。

## 适合谁

这个项目适合想要一个不联网、权限少、能处理长篇 TXT 的安卓阅读器，也适合作为 Compose 长文本界面的参考。代码规模不大，阅读和搜索路径集中，便于继续改翻页效果或补充分章规则。
